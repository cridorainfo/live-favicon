# React example

A small Vite + React + TypeScript app demonstrating `@live-favicon/react`:
`useFaviconState`, `useFaviconTask`, and the imperative `favicon` singleton.

## Run it

From the repo root:

```bash
npm install
npm run dev --workspace=example-react
```

Then open the printed local URL and watch the browser tab while you type in
the search box, toggle the status indicator, or run a task.

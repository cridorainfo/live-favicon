New mail → icon change + sound + OTP autofill

A minimal inbox simulating what happens when a real email — including a one-time verification code — lands while you're on another tab: the favicon switches to a "new mail" icon, a chime plays, the tab title picks up the unread count, and the code is pulled out of the message body into the field below automatically, the way an OTP-autofill flow would.

This is a self-contained simulation for demo purposes — it doesn't connect to any real mailbox, and isn't affiliated with or endorsed by Google/Gmail. The red-envelope styling is just a familiar reference point for "new mail."

1. Receive mail

favicon.define("new-mail", ..., { sound: true }) once, then favicon.state("new-mail") per incoming message.
